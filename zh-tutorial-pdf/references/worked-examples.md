# 具体化：用真实数字走完整条流程

教程和论文的根本区别在这里。论文可以只给符号，教程必须给**数字**。

初学者卡住的地方几乎从来不是"定义没看懂"，而是"我不知道这东西实际长什么样"。
解决它的方法不是把措辞改得更精确，而是拿出真实输入、预设权重，
**一个矩阵一个向量地把每步运算和结果写清楚**。

## 怎么选维度和数字

| 要求 | 原因 | 反例 |
|---|---|---|
| 维度小到能印在纸上 | $d=512$ 没法在书里展开 | 直接贴真实模型的张量 |
| 但**不能退化** | 要保留转置、广播、多头切分的结构 | `d=1`、`T=1`、单头 —— 错了也看不出来 |
| 权重"不漂亮" | 全 1 / 单位阵会让错误隐形 | `W = I`、全 0.5 |
| 数值可心算验证 | 读者要能抽查一两个元素 | 17 位随机小数 |

经验取值：`T=3, d_model=4, d_k=2, n_heads=2`。三个 token 足以显示"谁注意谁"，
四维足以显示投影降维，两头足以显示切分与拼接。

## 每个数字必须由脚本生成

`../assets/worked_example.py` 是可直接运行的模板（纯标准库，已验证）。它同时输出两种形式：

- **人看的**：对齐的数值矩阵，便于自己核对
- **排版用的**：`\begin{bmatrix} ... \end{bmatrix}` 源码，直接粘进 `.tex`

```python
def latex_matrix(M, fmt="{:.4f}"):
    body = r" \\ ".join(" & ".join(fmt.format(v) for v in row) for row in M)
    return r"\begin{bmatrix} " + body + r" \end{bmatrix}"
```

**禁止手抄数字。** 手抄的数字从不经过任何检验，是教程里最容易出错的东西。

## 中间结果要全给

只给输入和输出等于没讲。注意力这一条链至少要印五步：

```
X            (3,4)  输入
Q = X W_Q    (3,2)  投影
K = X W_K    (3,2)
S = Q Kᵀ     (3,3)  未缩放打分          ← 关键：先给未缩放的
S / √d_k     (3,3)  缩放后              ← 才能看出缩放到底改变了什么
A = softmax  (3,3)  注意力权重
Out = A V    (3,2)  输出
```

真实输出长这样（`assets/worked_example.py` 的实际结果，非杜撰）：

```
S = Q K^T  未缩放打分  (3, 3)
   [ 8.2500   4.0000   8.5000]
   [ 9.0000   3.5000   6.2500]
   [ 6.7500   2.5000   4.2500]

A = softmax(S/sqrt(d_k))  注意力权重  (3, 3)
   [ 0.4459   0.0221   0.5321]
   [ 0.8595   0.0176   0.1229]
   [ 0.8195   0.0406   0.1399]

   检查点：A 每行之和 = 1.0000000000  1.0000000000  1.0000000000  (应当都是 1)
```

## 给读者可自查的检查点

每个算例都要埋几个读者能自己验证的不变量，这比任何保证都有说服力：

- softmax 每行之和为 1
- 注意力矩阵在无 mask 时全部非负
- LayerNorm 后每行均值 0、方差 1
- 因果 mask 后上三角为 0
- 梯度检查：数值差分与反传结果相符

## 把矩阵翻译成人话

矩阵印完要用文字解读一遍，否则读者只看到一堆数：

```
逐 token 解读：
  token1 「猫」把注意力分给 —— 猫:0.446  坐:0.022  垫:0.532
  token2 「坐」把注意力分给 —— 猫:0.859  坐:0.018  垫:0.123
```

这一步让"注意力权重"从抽象名词变成"这个词在看哪个词"。

## 全书贯穿同一个案例

复杂主题不要每节换新例子 —— 连续性才是让人开窍的东西。选定一个小案例
（比如三个词的一句话），从 tokenize、embedding、位置编码、注意力、FFN、
LayerNorm 一路到 logits 和采样，**每一节都在上一节的数字上继续往下算**。

读者读到第 8 节时手里还攥着第 1 节那三个 token，这种连贯感是单独的玩具例子给不了的。

太大而无法完整展开的部分（如真实词表 softmax），就把小规模版本讲透，
再明确说明"真实规模下这一步是 $50257$ 维，结构完全相同"。

## 反模式

- ❌ 只给符号推导，末尾附一句"具体数值见代码"
- ❌ 例子里维度全相等（$T=d_k=n$），读者分不清哪个轴是哪个
- ❌ 中间步骤跳过，直接从输入跳到输出
- ❌ 每节一个互不相干的新例子
- ❌ 数字手算誊抄进正文
- ❌ 印了矩阵却不解释它的含义
